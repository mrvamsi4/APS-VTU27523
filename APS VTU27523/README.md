# Applied Programming Skills — 85 LeetCode Java Solutions

This folder contains Java solution snippets for all 85 tasks listed in the uploaded Task Mapping PDF, organized by task number.

## How to use
- Each `.java` file contains the LeetCode solution class or design class for that problem.
- Copy the code into the corresponding LeetCode problem's editor.
- For linked-list problems, LeetCode provides `ListNode`; for binary-tree problems, LeetCode provides `TreeNode`. Do not add your own definitions on LeetCode.
- Design problems use the required class names such as `MinStack`, `MyQueue`, `StockSpanner`, `MyCircularQueue`, `MyCircularDeque`, and `RecentCounter`.
- Files are separate because many LeetCode tasks use the same class name (`Solution`).
- These are concise reference implementations. Read the problem statement and test edge cases before submitting.
